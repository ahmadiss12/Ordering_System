# Project structure

What lives in each folder today, and what will land there later. When you are unsure
where a new file belongs, jump to [The one rule to remember](#the-one-rule-to-remember).

## Root — build rules

| File | Holds | Later |
|---|---|---|
| `global.json` | Pins .NET SDK 10 | Bump on major upgrade |
| `.editorconfig` | Code style + which analyzer rules are off, with reasons | New suppressions, always with a comment |
| `api/Directory.Build.props` | Settings for **all** projects: `net10.0`, nullable, warnings-as-errors | Rarely touched |
| `api/Directory.Packages.props` | **Every NuGet version, once.** Projects reference packages with no version | Add a line per new package |
| `api/tests/Directory.Build.props` | Test-only settings + the shared xUnit/Shouldly references | Rarely |
| `api/OrderingSystem.slnx` | Lists the 7 projects | New project = new line |

## Application — what the system *does*

| File | Holds | Later |
|---|---|---|
| `Abstractions/IAppDbContext.cs` | The 26 `DbSet`s + `SaveChangesAsync` | One line per new table |
| `Abstractions/ITenantContext.cs` | Who's asking: `UserId`, `RestaurantId`, `IsPlatformAdmin` | Stable |
| `Abstractions/IClock.cs` | Time as a dependency, so tests can move it | Stable |
| *(new)* `Abstractions/IEmailSender.cs` | — | Password reset (Step 7) |
| *(new)* `Abstractions/IPaymentGateway.cs` | — | Phase 3 |
| *(new)* `Features/<Name>/` | — | **Where all the real work goes** |

Each `Features/` folder holds three kinds of file together:

```
Features/Orders/
  PlaceOrder.cs            the use case — the logic
  PlaceOrderRequest.cs     DTO in
  OrderResponse.cs         DTO out
  PlaceOrderValidator.cs   FluentValidation rules
```

Planned: `Auth`, `Restaurants`, `Menu`, `Options`, `Cart`, `Orders`, `Addresses`,
`Zones`, `Settlement`, `Reports`.

## The one rule to remember

**Ask "what kind of thing is this?"**

| It's… | Goes in |
|---|---|
| A business rule that's true regardless of tech | `Domain` |
| A thing a user can *do* | `Application/Features/` |
| How we talk to a database, email server, gateway | `Infrastructure` |
| A URL | `Api/Controllers` |
